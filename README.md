* **Interactive Frame-Canvas Scroll Engine:** Custom HTML5 Canvas preloader and smooth frame animation synchronized with scroll behavior.

## 🚀 Getting Started Locally

### Prerequisites
* [Node.js](https://nodejs.org/) (v14+ recommended)

### Installation & Execution

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yashkose014-dotcom/Yash-Kose-Portfolio.git
   cd Yash-Kose-Portfolio
   ```

2. **Start the local development server:**
   ```bash
   npm start
   # or
   npm run dev
   ```

3. **Open in browser:**
   Navigate to `http://localhost:3000` (or `http://127.0.0.1:3000`).

Alternatively, you can open `index.html` directly in any web browser or use VS Code Live Server.
